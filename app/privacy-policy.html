Privacy Policy

Last updated: June 4, 2026

✅ This app does NOT collect, store, or transmit any personal user data. All AI inference runs 100% on your device.

📋 1. Overview

Mobile API Server is a tool application that runs AI large language models locally on Android devices and provides services through an OpenAI-compatible API. We highly value your privacy.

🚫 2. Data Collection

This app does not collect, store, or transmit any personal user information. All AI model inference is completed entirely on your device locally. Your conversation content, model configuration, or any data will not be sent to any remote server.

🔑 3. Permission Details

This app requests the following permissions:

  • Storage Permission (MANAGE_EXTERNAL_STORAGE / READ_MEDIA_IMAGES): Read and manage AI model files and user-selected images.
  • Notification Permission (POST_NOTIFICATIONS): Display API service status when the foreground service is running.
  • Foreground Service Permission (FOREGROUND_SERVICE / FOREGROUND_SERVICE_SPECIAL_USE): Continuously run the API server in the background.
  • Network Permission (INTERNET): Provide API services on the local network.
  • Wake Lock (WAKE_LOCK): Keep the device running during long inference sessions.

💾 4. Local Data Storage

All configuration and conversation data are stored only locally on your device (SharedPreferences) and will not be uploaded or synced to any cloud.

🏢 5. Third-party Services

This app does not integrate any third-party analytics, advertising, or data collection services.

📦 6. Open Source Components

  • LiteRT LM — Google AI Edge local inference engine
  • Ktor — Kotlin HTTP server framework
  • OkHttp — HTTP client
  • Markwon — Markdown rendering

📧 7. Contact

For privacy-related questions, please contact us through GitHub Issues.

隐私政策

✅ 本应用不收集、不存储、不传输任何用户个人数据。所有AI推理100%在您的设备本地完成。

📋 1. 概述

Mobile API Server（以下简称"本应用"）是一款在 Android 设备本地运行 AI 大语言模型并通过 OpenAI 兼容 API 提供服务的工具应用。我们高度重视您的隐私。

🚫 2. 数据收集

本应用不收集、不存储、不传输任何用户个人信息。所有 AI 模型推理完全在您的设备本地完成，不会将您的对话内容、模型配置或任何数据发送到任何远程服务器。

🔑 3. 权限说明

本应用请求以下权限：

  • 存储权限（MANAGE_EXTERNAL_STORAGE / READ_MEDIA_IMAGES）：读取和管理设备上的 AI 模型文件及用户选择的图片。
  • 通知权限（POST_NOTIFICATIONS）：在前台服务运行时显示 API 服务状态通知。
  • 前台服务权限（FOREGROUND_SERVICE / FOREGROUND_SERVICE_SPECIAL_USE）：在后台持续运行 API 服务器。
  • 网络权限（INTERNET）：在本地网络提供 API 服务。
  • 唤醒锁（WAKE_LOCK）：在长时间推理期间保持设备运行。

💾 4. 本地数据存储

本应用的所有配置和对话数据仅存储在您的设备本地（SharedPreferences），不会上传或同步到任何云端。

🏢 5. 第三方服务

本应用不集成任何第三方分析、广告或数据收集服务。

📦 6. 开源组件

  • LiteRT LM — Google AI Edge 本地推理引擎
  • Ktor — Kotlin HTTP 服务器框架
  • OkHttp — HTTP 客户端
  • Markwon — Markdown 渲染
